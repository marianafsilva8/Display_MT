# Estudo da Propriedade Display no CSS

## 📋 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de estudar, praticar e consolidar o entendimento sobre a propriedade **`display`** no CSS. A propriedade `display` é uma das mais importantes para o controle de layout na web, definindo como os elementos se comportam no fluxo do documento.

O repositório contém exemplos práticos e visuais demonstrando o funcionamento dos seguintes valores:
* **`none`**: Oculta o elemento completamente da página, removendo-o do fluxo visual.
* **`block`**: Ocupa toda a largura disponível, quebrando a linha antes e depois do elemento.
* **`inline`**: Ocupa apenas o espaço necessário para o seu conteúdo e não quebra linhas.
* **`inline-block`**: Permite que os elementos fiquem lado a lado (como *inline*), mas aceita propriedades de largura, altura e espaçamentos (como *block*).
* **`flex`**: Ativa o **Flexbox**, um modelo de layout unidimensional poderoso para distribuição de espaço e alinhamento de itens.
